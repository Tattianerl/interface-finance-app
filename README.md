# Finances App

Este é um aplicativo de gestão financeira desenvolvido para ajudar microempreendedores a controlarem suas finanças de forma eficiente. O projeto oferece funcionalidades de registro de despesas e receitas, além de uma interface simples e intuitiva para visualização dos dados financeiros.

## Tecnologias Utilizadas

- **Frontend**: React (Vite + Tailwind CSS)
- **Backend**: Node.js (Express), MongoDB (Prisma)
- **Deploy**: Vercel

## Funcionalidades

- **Registro de Despesas**: O usuário pode cadastrar despesas informando o título, valor, categoria e a data da despesa.
- **Controle de Saldo**: O aplicativo calcula automaticamente o saldo baseado nas entradas e saídas registradas.
- **Dashboard**: Exibe o total de despesas e receitas, além de gráficos com os dados financeiros.
- **Autenticação**: Embora sem criptografia, o sistema realiza uma validação simples de login.
- **Relatórios**: Geração de relatórios financeiros com filtros por data e categoria.
